# Easy Yapping Landingpage

Statischer Entwurf für **Easy Yapping for Female Brands**.

## Lokale Vorschau

```bash
python3 -m http.server 8080
```

Danach im Browser `http://localhost:8080` öffnen.

## Challenge-Seite

Die Challenge-Seite liegt unter `challenge/` und ist über
`http://localhost:8080/challenge/` erreichbar. Im Header steht der Tagesimpuls vor dem
Daily-Tracking. Das Daily-Tracking verlinkt das bestehende Jotform; dessen Felder und
E-Mail-/Excel-Anbindung müssen noch im Verwaltungsbereich angepasst und geprüft werden.
Es gibt keine lokale Demo-Speicherung, Demo-Zähler oder öffentliche Namensanzeigen.

Woche 1 ist zugänglich, zukünftige Wochen sind nicht im öffentlichen HTML/JS enthalten.
Weitere Wochen erst zum jeweiligen Freigabetermin ausliefern. Der aktuelle Guide liegt
unter `challenge/assets/so-gehts-easy-yapping.pdf`; das ausfüllbare Wochen-Worksheet unter `challenge/assets/worksheet-woche-1.pdf`.
WhatsApp-Link und Tag 7 bleiben offen. Die interne Prüfliste steht in `challenge/PRUEFSTAND.md`.
