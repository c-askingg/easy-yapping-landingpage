# Easy Yapping Landingpage

Statischer Entwurf für **Easy Yapping for Female Brands**.

## Lokale Vorschau

```bash
python3 -m http.server 8080
```

Danach im Browser `http://localhost:8080` öffnen.

## Inhaltlicher Status

- Alle Buchungs-Buttons verlinken auf Digistore24.
- Impressum und Datenschutz sind verlinkt.
- Testimonials sind absichtlich noch nicht enthalten, bis ihre Freigabe vorliegt.
